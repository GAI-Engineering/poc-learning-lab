# Contributing

- Run a POC: each `notebooks/NN-*/poc/` folder is self-contained Python 3 (stdlib + matplotlib for charts). Run it, compare your output with `runs/`.
- Comment: GitHub Issues — one thread per notebook, seeded with its community question. (Discussions are not enabled on this repo; Issues are the discussion surface.)
- Corrections are welcome; evidence wins arguments here. All data is synthetic.
