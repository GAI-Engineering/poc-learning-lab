# POC Learning Lab — Agents That See · Agents That Talk

A public learning lab from **GAI Observe LLC**: fifteen proof-of-concept builds for multi-agent systems that perceive the world and coordinate in conversation — plus two data studies. Each POC is implemented here as a runnable reference build with its recorded runs, and documented as a study notebook with its sources, data, charts and learning evidence.

Every notebook began as a teaching post in the series *Agents That See · Agents That Talk*. Each one names one idea worth stealing, shows a buildable POC, states its guardrail, and says plainly where it breaks.

## How to use this lab

- Each folder under `notebooks/` is self-contained: a README summary, the source pack the study notebook was built from, the data tables, the charts, and three study artifacts (briefing, study guide, FAQ).
- Data and charts are labelled **MEASURED** (from runs we executed and recorded) or **ILLUSTRATIVE** (worked examples that teach the pattern). They are never blended.
- Comment and question in **Discussions** — one thread per notebook, seeded with its community question. Corrections are welcome; evidence wins arguments here.
