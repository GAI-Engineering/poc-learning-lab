# POC Brief — The Debate Pattern (06)

**Idea:** Stress-test a contract position before a human negotiates it, with two advocates forbidden to agree and a judge who must rule in a format a machine can read.
**Build steps:** (1) A Proponent builds the strongest case for each position, evidence first; an Opponent builds the strongest case against, offering no alternatives; neither concedes. (2) A Judge applies a fixed rule stated before the debate (margin of scripted argument strength) and returns PROCEED, PAUSE or REJECT with the strongest point each way. (3) Record the verdict log and a disagreement score per claim — where both sides fight hardest and neither wins cleanly is where the genuine uncertainty lives. (4) File the strongest losing argument: that map of the fight is the risk register.
**Guardrail:** The verdict informs counsel. It never accepts, signs, or advises a client.
**Win condition:** One argument surfaces that the team had not considered — and the verdict is parseable, not prose.
Data: synthetic only. Model: deterministic stub, no live model.
